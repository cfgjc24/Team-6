**Frontend**: React
**Backend**: Python, Flask

### Running Locally

Run the backend server first:

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

Then in a separate terminal, run the frontend server:

```bash
cd frontend
npm install
npm start
```
